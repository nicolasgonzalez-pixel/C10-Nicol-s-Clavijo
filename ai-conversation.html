Create and deploy an individual interactive decision webpage that allows users to enter, modify, and analyze decision-making problems under uncertainty. Use the C10 reference dashboard as the functional model and apply your learning from C1–C9.

Requirements

1. Interactive decision model. Develop a webpage that allows users to:

• Add, edit, and remove alternatives and states of nature.

• Enter and modify payoff values in an interactive table.

• Enter and adjust state probabilities for probabilistic criteria.

• Calculate and compare Maximax, Maximin, Minimax Regret, and EMV/Bayes, including the corresponding values and recommended alternatives.

• Apply staged filtering and visualize each elimination step.

• Display a flow diagram representing the staged-filtering process and its final outcome.

All calculations and visualizations must update automatically when the input data change. Correctly identify ties when applicable.

2. Preloaded examples. Include at least two distinct, preloaded decision problems that users can select directly from the webpage. Each example must contain alternatives, states of nature, payoff values, and probabilities. The examples must demonstrate and allow users to verify the correct functioning of all decision criteria, staged filtering, and the flow diagram.

3. Functionality and usability. Ensure the webpage is accurate, responsive, and easy to use. Clearly organize the input tables, calculation results, filtering stages, and flow diagram. Handle invalid inputs appropriately and ensure consistency between all displayed results.

4. AI development record. Include a visible, accessible hyperlink to the AI conversation used to develop the webpage.

5. Submission. Submit only the deployed webpage URL, publicly accessible through a web browser. No written decision context, separate analysis, or additional document is required.
